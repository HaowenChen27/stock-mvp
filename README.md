# Stock Strength MVP

一个最小可用的盯盘工具原型，用来自动识别少量股票 / ETF 的**强弱**与**走势状态**。

当前版本的目标不是做自动交易，也不是做完整交易终端，而是先把这几件事做好：

- 自动同步少量标的的实时行情
- 给每个标的打出强弱分数
- 给出走势标签（强势上攻、强势震荡、冲高回落、横盘整理、走弱下行）
- 做简单的成对对比（如中国电建 vs 中国西电、半导体 ETF vs 光伏 ETF）
- 支持手动覆盖行情，便于调试评分模型

## 功能概览

- 股票 / ETF 强弱打分
- 走势标签识别
- 板块强弱面板
- 成对比较视图
- AkShare 实时行情同步（当前通过雪球单票实时接口）
- 自动定时同步
- 页面自动刷新
- 分数变化高亮

## 当前默认标的

- 中国电建（601669）
- 中国西电（601179）
- 半导体 ETF（512480）
- 光伏 ETF（515790）

- **后端**：Node.js 原生 HTTP 服务
- **前端**：原生 HTML / CSS / JavaScript
- **行情同步**：Python + AkShare

## 安装与启动

### 1. 克隆仓库

```bash
git clone https://github.com/HaowenChen27/stock-mvp.git
cd stock-mvp
```

### 2. 创建 Python 虚拟环境并安装依赖

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
```

### 3. 启动服务

```bash
node server.mjs
```

启动后默认监听：

```text
http://localhost:3088
```

浏览器打开这个地址即可。

## 使用方式

### 手动同步实时行情

页面顶部点击：

- `同步真实行情`

系统会调用 AkShare 拉取最新可用行情，并重新计算：

- 强弱分
- 走势标签
- 对比结论
- 板块联动结果

### 开启自动同步

页面支持：

- 15 秒
- 30 秒
- 60 秒

自动同步会定时刷新页面中的评分与走势结果。

### 手动覆盖行情数据

页面底部表单可以手动填写：

- 代码
- 现价
- 今开
- 最高
- 最低
- 昨收
- 分时轨迹

这部分主要用于：

- 调试评分模型
- 验证某种走势标签是否符合预期
- 在无实时行情时做离线演示

## 评分逻辑（当前版本）

当前版本有意**弱化**这些字段的影响：

- 量比
- 竞价额
- 成交额

原因是免费公开接口在这些字段上的口径并不稳定，容易误导判断。

当前评分更依赖：

- 涨跌幅
- 高开幅度
- 当前价格在日内区间的位置
- 分时轨迹变化
- 板块联动强弱

这意味着它更像一个：

**基于价格行为和板块联动的盯盘工具**

而不是一个依赖精细盘口口径的交易终端。

## 适用场景

这个项目当前更适合：

- 盯少量自选标的
- 做盘中强弱观察
- 快速比较两个方向谁更强
- 验证自己的一套盯盘逻辑

不适合直接拿来做：

- 自动交易
- 高频策略
- 盘口级量化
- 大规模股票池扫描

## 已知限制

- 实时行情依赖公开可用的数据接口，稳定性不如专业终端
- 当前默认只适合少量标的盯盘
- 板块数据是轻量级聚合，不是完整行业终端口径
- 非交易时段看到的是最近一次可用快照，不会持续跳动
